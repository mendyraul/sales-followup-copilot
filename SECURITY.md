# Security reporting

Report security issues privately through this repository's **Security → Advisories → Report a vulnerability** page. Do not post credentials or customer information in a public issue. Include the affected version, minimal reproduction and impact; use fictional records.

The current release is an early open-source pilot. Keep it updated, use HTTPS for remote access, retain workspace isolation, and preserve your private environment file and encryption key. The fictional demo bypasses authentication only in explicit loopback demo mode; use authenticated self-host mode for real records.

OAuth credentials, sessions and provider keys are excluded from workspace exports. Gmail conversations become visible to workspace members only when a user explicitly attaches them. No external telemetry is enabled. Optional AI calls share the user-selected context with the configured provider after confirmation; consult the provider's data policy.

Supported fixes target the latest tagged release. We do not promise a response-time SLA.
