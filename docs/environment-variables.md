# Environment variables

Keep `.env` private and untracked. `scripts/setup.mjs` generates a self-host configuration with unique secrets; `.env.example` documents source/demo settings and contains no usable authentication secret. Existing process variables override the file. Compose supplies its own internal DATABASE_URL.

| Variable                                         | Purpose                                                                                                                                                                                                                          |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APP_MODE                                         | `selfhost` for authenticated work; explicit `demo` is loopback-only and bypasses sign-in.                                                                                                                                        |
| APP_URL                                          | Exact browser origin, including port locally or HTTPS remotely. Setup uses `http://127.0.0.1:3116`.                                                                                                                              |
| PORT                                             | Compose loopback host port; setup 3116, fictional demo 3115. Match APP_URL.                                                                                                                                                      |
| DATABASE_URL                                     | Source/worker Prisma PostgreSQL URL. Compose sets this to its private database.                                                                                                                                                  |
| POSTGRES_PASSWORD                                | Unique Compose database password generated at setup. Do not change without updating the actual database role.                                                                                                                    |
| BETTER_AUTH_SECRET                               | Random 32+ character authentication secret. Generated at setup; retain across upgrades.                                                                                                                                          |
| TOKEN_ENCRYPTION_KEY                             | 64 hexadecimal characters (32 random bytes) for Gmail credentials. Generated at setup; retain for decrypting existing tokens.                                                                                                    |
| SMTP_URL / SMTP_FROM                             | Optional SMTP connection URI and sender for invitations, opted-in reminders and digests. Missing values leave in-app notifications available.                                                                                    |
| GMAIL_ENABLED                                    | Exact `true` enables the optional Gmail connector if its credentials and encryption key are configured.                                                                                                                          |
| GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET          | Operator's OAuth application. Register `APP_URL/api/inbox/callback` as the redirect URI and configure `gmail.readonly`. Google may require app verification; use explicit test users during evaluation.                          |
| AI_PROVIDER                                      | `mock` (or `template`) for local drafts; `openai` for optional external generation.                                                                                                                                              |
| AI_API_KEY / AI_MODEL                            | Server-side OpenAI key and optional model override. The inherited default is `gpt-4o-mini`. No keys reach the browser or exports.                                                                                                |
| AI_DAILY_REQUEST_LIMIT / AI_INSTANCE_DAILY_LIMIT | Per-workspace/per-instance daily request caps, defaults 20/100. Requests require an explicit confirmation, cap output at 700 tokens and time out after 20 seconds. Failed reserved requests count conservatively toward the cap. |
| FEEDBACK_CAPTURE_ENABLED                         | Exact `false` rejects private feedback writes. Default enabled.                                                                                                                                                                  |
| FEEDBACK_DEFAULT_CHANNEL                         | Saved private feedback channel; default `in_app`.                                                                                                                                                                                |
| FOLLOW_THROUGH_IMAGE                             | Optional Compose image tag; defaults to `follow-through:0.2.0`.                                                                                                                                                                  |
| DB_PORT                                          | Fictional demo database host port only; default 5617. Match its source DATABASE_URL.                                                                                                                                             |
| SEND_MODE                                        | Compatibility setting. Prospect delivery has no implementation and remains disabled.                                                                                                                                             |

Gmail read-only access cannot send messages. A member must explicitly attach a thread and confirm sharing it with the workspace. The worker syncs attached threads approximately every five minutes. Disconnect revokes the connection and offers removal of imported copies; notes and draft text authored by people remain. Mail attachments are not imported.

SMTP reminders describe work assigned to a member; they do not send prospect follow-ups. Definitive transient errors retry, while ambiguous delivery is surfaced for a human decision. In-app notifications work without SMTP, but the worker must run.

Optional OpenAI requests use the selected notes/messages, lead context and writing profile; source selections and profile version remain with the draft. Requests set `store: false`, which does not guarantee zero retention under provider policy. Default templates make no external calls. No real provider credentials or calls are needed for CI.
