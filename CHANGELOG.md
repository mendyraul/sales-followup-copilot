# Changelog

## 0.2.0 — 2026-10-27

First MIT open-source pilot: authenticated workspaces, owner/member invitations and handoffs; scheduled next actions and true contact timestamps; durable reminders and optional SMTP digest; quick interaction logging; optional read-only Gmail; saved writing profiles and selected draft provenance; reviewed duplicates/merges; credential-free JSON export/new-workspace restore; onboarding and reviewed maintainer feedback. Includes cursor pagination, Docker installation, worker health, private backups, operator documentation and native release archives.

Core workflows require no external paid services. Prospect sending remains manual in the user's inbox. Optional services require operator credentials and live acceptance testing.
